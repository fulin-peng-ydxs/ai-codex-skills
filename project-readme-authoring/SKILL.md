# 项目 README 编写

## 职责与边界

README 是项目使用与开发的主入口，回答“这是什么、如何开始、常用任务怎么做、深入内容在哪里”。本文维护执行流程与命令来源接入；[输出契约](references/output-contract.md) 维护内容与读者检查。

本技能维护 README 的命令来源选择及前置确认，命令发现与验证复用 [AI 约束文档编写](../ai-constraint-doc-authoring/SKILL.md) 的方法与共用门禁。需要补建或修订项目协作入口及其命令正文时，在授权范围调用该技能；不因复用验证方法启动整份约束文档生成。`CLAUDE.md` 只用于定位权威入口。

技术机制由系统架构、模块/技术专题文档维护，逐环节状态、权限与数据规则由业务闭环文档维护，交付完整性和接手风险由接手报告维护。README 保留自足使用与开发定位所需的摘要、步骤和精简目录导航；结构说明的深度按输出契约区分，不复制专题正文，也不自动生成缺少的专题。

## 输入与前置条件

确定仓库、README 路径和操作类型，读取项目规范及现有文档。首次生成或整体重构完整读取输出契约；局部更新只读取受影响要求。仅保存原文时核对基线和有效修正，不重新分析、扩写或启动命令验证，不新增验证声明。

### 命令来源前置

首次生成、整体重构或调整运行/开发路径时应用本节。正常路径从项目 `AGENTS.md` 或其明确指向的命令正文取得命令、执行目录、前提、成功判据及清理方式；内容完整且无失效线索时直接复用，不为 README 重验，也不要求证明由哪次技能调用生成。

- 入口缺失、命令缺失、验证依据不明或文档与相关脚本/配置冲突时，先查项目脚本、构建配置、已有操作指南和可取得的验证证据，形成缺口及候选修订；不能仅因文件名不同就否定真实依据，也不能把静态发现当成执行成功。
- 已有授权覆盖补建或修订命令入口时，调用约束文档技能完成所需补齐并执行门禁；未覆盖时，展示拟新增/修改文件、所需验证和影响，请用户选择先补齐入口，或采用明确的替代来源与交付范围。默认建议恢复正常前置；不因编写 README 自动创建 AGENTS/CLAUDE，也不直接跳过来源前置。确认按 [全局确认机制](~/ai-agent-config/config/force/collaboration-rule.md#需要先确认时) 执行，已有覆盖本次决定的授权直接复用。
- 用户批准采用现有项目指南、脚本或构建配置作为替代来源时，复用约束文档技能的命令发现方法和 [验证门禁](../ai-constraint-doc-authoring/references/verification-gate.md)，在批准范围处理；说明该来源维护什么、README 只保留哪些使用片段，不另建平行命令定义。批准更换来源不等于批准省略验证；仍有验证缺口时按共用门禁的“前置受限与例外确认”准备方案，由本技能取得必要确认并承接交付限制。一次确认可覆盖已说明的来源替代与验证限制，不拆成重复审批。
- 待决定时继续项目定位、导航等不依赖缺口的工作，保留既有有效内容；仅保存原文或不涉及命令的局部修订不触发补建入口或无关验证。

## 执行流程

1. **核实入口事实**：读取现有 README、AGENTS、构建清单、主要源码入口及相关专题文档，核实定位、能力和目录。命令事实按第 3 步复用；源码或配置与文档冲突时说明差异，不自行编出替代命令。
2. **按读者任务组织**：读取 [输出契约](references/output-contract.md)，串联准备、首次使用、常用开发任务、结果和故障入口；核对已有专题的权威位置。
3. **取得权威命令**：按 [命令来源前置](#命令来源前置) 判断来源复用、补齐或替代分支；需要发现或验证命令时读取共用方法与门禁，涉及入口维护时按授权调用约束文档技能。
4. **写入与联动**：从正常权威来源或用户批准的替代来源选择最小使用路径所需内容，保留执行条件并注明项目内来源链接。验证受阻时保留实际命令证据状态及获准例外的范围与限制；未获相应批准不写入依赖例外的流程，继续不受影响的内容，不把失败/未验证候选写成可用流程。标题变化时修复受影响锚点，专题变化只同步摘要和导航。
5. **检查与交付**：按输出契约走读实际使用路径，运行 `scripts/validate_readme_structure.py <README-path>`。新建和整体重构按固定模板检查；保存和局部更新保留基线，必要时使用 `--existing-structure` 做基础检查，不宣称全文模板合规。

## 核心约束

默认简体中文；代码、标识及引用原文保留项目实际写法，用户明确要求优先。README 描述当前有效能力，不把计划、历史流程或静态命令发现写成已实现、已验证。不输出密钥、私人账号或不可复用的本机路径。

## 产出边界与交付

产物为目标 README.md；采用输出契约的固定模板，按其要求落实文档边界、引用选择与协作入口。保留当前有效内容，局部更新和保存不重排无关部分。

交付文件绝对路径、变更范围、实际命令来源、本次是否调用上游技能及其结果、适用的例外批准与限制、内容校验和剩余缺口。复用既有证据不等于本次重新执行，不能新增运行通过声明。

## 验证与完成标准

文档校验器复用同级 `skill-authoring-standard/scripts/validate_document_template.py`，其统一消费 `ai-constraint-doc-authoring/scripts/document_markdown.py`；结构从权威模板读取，不在脚本另写字段清单。安装或同步时同级提供两个依赖，缺失明确报错。

结构校验与内容验收分开：检查项目定位、适用最低内容、路径和链接，以及 README 的命令、参数、执行目录、前提和验证状态是否与权威来源一致；沿最小使用路径确认前置条件、步骤、成功结果和失败检查点能衔接。只保存时核对原文与确认状态，不把保存成功当作运行验证。
