# 设计合规固定模板

执行与保存见 [技能入口](../SKILL.md)；模板语法与检查命令见 [共用模板检查用法](../../skill-authoring-standard/references/template-validation.md)。填写后按本文内容验收核对。

## 完整模板

````document-template
# 设计合规报告

## 结论与范围

- 检查时点与代码/版本范围：{{@实际内容、来源及限制}}
- DESIGN 文档：{{@通过 / 不通过 / 需要补齐 / 无法判断 / 未审查；缺失或不可访问时说明事实及限制}}
- 实现遵循：{{@通过 / 不通过 / 需要补齐 / 无法判断 / 未审查}}
- 页面 / 模块 / 文件：{{@实际内容、来源及限制}}
- DESIGN 事实源与适用版本：{{@实际内容、来源及限制}}
- 审查方式：{{@静态 / 实测 / diff 对照}}
- 视口与输入方式：{{@项目支持范围及来源、实际检查的视口和输入方式、未覆盖范围及原因；移动端仅在适用时列入，未实测不写成不适用}}

## 问题与复核

### {{@问题编号}}：{{@标题}} <!-- repeat -->

类别：{{@DESIGN 文档自身问题 / 实现违反硬规则 / 默认规范偏离 / 维护闭环缺口。}}
优先级：{{@按技能入口的优先级规则填写等级及定级依据}}

- 依据与位置：{{@DESIGN 规则/文档位置、项目证据及适用的实现位置}}
- 现象与影响：{{@实际偏离、为何不合规及影响；文档与实现分别按技能入口定级}}
- 修复方向：{{@最小改动及需同步的事实源/注册/schema/token/测试/文档}}
- 复核：{{@条件、操作、符合契约的预期结果；实际已运行/未运行及原因、结果与证据}}
- 当前状态及例外：{{@建议/已实施/待复核等真实状态；适用的已确认例外及依据、规则冲突或需确认的偏离与影响}}

## 覆盖与剩余事项

{{@按契约或页面/状态概括已检查范围及结果，正常项也有覆盖说明；共用验证环境、已运行/未运行及原因、未审查与无法判断的部分。条目已有证据仅引用。}}

{{@跨问题的例外、冲突和未决事项及正文定位；无问题时省略空问题条目，仍保留文档与实现独立结论、检查范围和证据限制。}}
````

## 填写与内容验收

问题/风险按严重程度及处理优先级展示，沿用已有编号，不因排序重编。没有发现时不生成空问题条目，父节说明条目情况及已检查依据，仍保留结论、覆盖和盲区。复验安排不等于已执行，修复与验证状态分别记录。

每个问题在固定的优先级字段记录等级和依据；定级语义仅由 [技能入口的优先级规则](../SKILL.md#优先级) 维护，不在模板另设口径。
