# 方案、执行记录与归档

本文定义任务留痕与文件纳管；目录见 [工作空间](workspace.md)，授权执行见 [主流程](../SKILL.md)。记录是历史证据，不授予后续权限。产物遵守 [文档输出](~/ai-agent-config/config/force/document-output.md) 与 [文档边界](~/ai-agent-config/config/force/document-boundaries.md)。

## 本次记录

项目及运维根明确后，在 `OPS_ROOT/records/` 排他创建 Asia/Shanghai 时间目录 `YYYYMMDDHHmm`，重名追加 `-01`、`-02`；多服务器及原任务中的初始化共用记录。目录未定先收集资料，确定后补存真实原文。

默认只需 `record.md`，固定保留三个顶级章节：

```markdown
# 原需求
用户原文，补充按时间追加。

# 操作方案
各版提交审批的方案原文及对应批准/拒绝/撤销记录。

# 工作汇报
实际汇报原文、结果确认，以及执行证据、文件映射和归档状态。
```

原文内部标题、换行原样保存；来源消息、时间、版本及原文 SHA-256 放在段外。不用摘要重建缺失原文，拿不到完整源则记缺失并请求补充；未形成方案/汇报标状态，不编造。已批准内容不改写，修正追加新版本。含秘密仅在获准的非 Git 受控位置保存原件，仓内标清脱敏/删节；无法安全保存则停止该部分归档并报告。

动作多可另存 `commands.jsonl`，文件多可另存 `manifest.json`，已有 `approvals.json` 等继续使用；没有程序消费要求时不强制创建多份状态 JSON。下表是最低语义信息，不规定 JSON 键名：

| 证据 | 必须能查到 |
| --- | --- |
| 批准 | 类型（连接/执行/策略/结果）、用户来源、原文或可信引用、时间/有效范围、方案/规则版本及撤销条件 |
| 动作 | 服务器/单位、身份/目录、实际命令或工具参数、匹配规则与批准引用、起止时间、退出状态、脱敏结果及验证；只读同样记录 |
| 文件 | 服务器、远端绝对路径、动作、原始大小/类型/权限/属主/时间、前后哈希（可安全取得时）、本地路径或排除原因、脱敏状态 |
| 结果 | 成功/失败/跳过/回滚/未知和未完成项；服务器结果、用户确认、归档、Git 分开记录 |

## 方案与汇报

采用参考结构，围绕改动组织，不复制技能检查清单。短操作可一张表；多步脚本给完整内容或可持久查阅的文件及哈希，不只指临时副本。

**执行方案**：目标/版本及成功标准 → diff 或精确命令（身份、目录、顺序）→ 影响/窗口 → 必要备份与验证 → 失败停止条件、回退命令及触发条件 → 结果检查。只读任务在采集前提交范围/命令，无变更则说明不需变更备份和回滚。

**工作汇报**：梳理的需求、实际改动事项、结果。逐对象列动作与作用、非白名单动作及批准、验证和未完成项；无文件变化的启停/SQL/API 也登记。附文档/镜像 diff、排除项和拟提交文件。回读及文档更新先于结果审批。

## 文件镜像

- 仅纳管任务相关普通文件，原始大小须 **≤15,000,000 字节**。传输前后核验类型、大小、敏感性及漂移；超限、大小未知、秘密/数据备份不纳入内容，不靠压缩、分片、LFS 或脱敏变小绕过。超限只记元数据，不为算哈希读全文。
- 安全原件 `/etc/nginx/nginx.conf` 映射到 `servers/<server-id>/rootfs/etc/nginx/nginx.conf`；脱敏件加 `.redacted`，字段摘要加 `.summary.md`，不得用原配置名保存不可部署的投影。拒绝 `..`、跨 server-id 和本地祖先软链接逃逸。
- 软链接只记目标/元数据；设备、socket、FIFO、数据库数据目录不复制。私钥、密码、Token 和敏感原件即使很小也不进 Git。
- 首次修改前将合规基线存到本次 `baseline/<server-id>/rootfs/...`；已有 Git 基线仍核对远端漂移。最终回读写镜像，删除登记 tombstone；基线、附件和日志遵守相同大小/脱敏要求。
- 镜像不是完整备份，恢复所需权限/属主/ACL 等另记。真实备份按单位手册的受控位置维护；必要备份未验证时停止依赖变更。

## 结果审批与提交

证据形成即保存；完成回读、敏感信息检查、映射和汇报后，再请求结果及提交范围确认。审批后漂移须补充确认；拒绝/待补充保留待处理状态，不自动回滚或抹掉失败证据。

保留用户改动，不擅自 stash/reset；无关 staged 不得混入。批准后仅暂存明确文件，不用 `git add .` 代替范围确认，然后运行：

```bash
python3 <技能目录>/scripts/check_archive.py index --repo <仓库根> --operations-root <仓库相对运维目录>
```

检查覆盖运维目录整个索引快照的路径、对象类型和大小，不检查脱敏、原始大小或审批真实性；这些人工核对。超限历史文件先取得处置授权，不擅自删远端或重写历史；记录过大转受控外部归档，不截断原文。

复用提交消息技能，核对 hooks/filters 等隐式动作，再提交获批内容并回查一致性。报告 commit ID，不在提交内预写自身哈希，也不为记录它反复 amend。Git 失败只标归档未完成，不自动回滚服务器；push 单独授权。
