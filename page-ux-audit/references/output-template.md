# 页面体验审核产物模板

本文件维护产物结构与字段；适用条件、最低内容、固定项和完成标准由 [技能入口](../SKILL.md) 维护。首次完整输出读取；仅保存或局部更新保留原成果及证据状态。

按 [文档结构与输出规范](~/ai-agent-config/config/force/document-output.md) 使用默认骨架，以页面任务中的问题为审阅单元。必改、细节优化、风格统一及冗余交互是问题标签，不再要求分别建章；同一问题只写一处，保留全部相关判据和影响。
