# 磁盘使用分析

## 职责与边界

参考：[文档编写规范](~/ai-agent-config/config/force/document-output.md) · [通用协作规则](~/ai-agent-config/config/force/collaboration-rule.md)。

对分析对象默认只读。通过当前时刻的只读快照回答磁盘还剩多少空间、哪些目录占用最高、主要存放什么，以及哪些内容值得优先清理。

## 输入与前置条件

以用户指定的卷或目录为扫描范围，未指定时分析主目录；识别可访问范围及权限限制，不能将局部扫描报告成全盘统计。

## 执行流程

1. 确认目标卷和扫描范围，先采集总容量、已用、可用空间及使用率。
2. 从目标目录逐层定位高占用子目录和大文件；避免从系统根目录进行无边界递归扫描。
3. 将结果归入缓存与日志、开发构建、容器与虚拟化、聊天与同步、下载与文档等真实存在的类别。
4. 结合目录内容判断用途、清理价值和风险；无法确认时标记为待进一步检查，不把目录名推断写成事实。
5. 输出结构化报告。用户要求实际清理时，先完整读取并遵守 [清理安全规则](references/cleanup-safety.md)。

## 核心约束

- 结论必须来自本次命令输出；瞬时变化、权限不足和无法可靠测量的内容要明确说明。
- 不将系统目录、关键应用数据、工作文档、聊天记录或凭据列为常规清理项；用途不明时先作必要的只读核实，仍无法确定则标记待核实，不执行清理。

## 产出边界与交付

默认在对话中交付分析，用户要求保存时按指定路径或全局目录规则落盘。

完整报告生成前读取 [固定产物模板](references/output-template.md)，由其唯一维护目录、字段及内容验收；只要求摘要或局部分析时遵循明确范围，保存和局部更新保留基线。

## 验证与完成标准

核对容量与目录统计的范围、采样时点和单位；用途推断、预计可释放空间与实际释放量分别表达，权限或测量缺口如实保留。

完整生成后运行 `python3 <skills-root>/skill-authoring-standard/scripts/validate_document_template.py <报告路径> --template <本技能目录>/references/output-template.md`；实际采样事实及操作授权另行核对。
