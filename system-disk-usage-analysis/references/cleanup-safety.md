# 磁盘清理安全规则

本流程仅用于用户要求的磁盘清理；普通分析及符合自动回收条件的任务内临时产物收尾不适用。

## 锁定目标

执行任何清理前，逐项解析并验证目标：

- 使用完整、明确的文件或目录路径，核实实际路径和链接指向，不依赖未解析的环境变量、通配符或命令替换；不得使用宽泛递归删除。
- 说明内容类型、当前大小、预计可释放空间和风险等级。
- 不将系统根目录、用户主目录、整个工作区或共享临时根目录作为宽泛删除目标。
- 对聊天记录、同步盘、数据库、容器卷、密钥和工作资料标记高风险；无法判断时不执行。

## 取得确认

执行前展示最终清单、处理方式、影响和可恢复性；命令行操作同时展示精确命令。确认授权覆盖本次目标、动作及不可恢复影响，未覆盖时只补充确认差异。

## 执行与复核

- 只处理确认清单中的目标，优先使用移到废纸篓、应用自带清理或其它可恢复方式。
- 完成后重新采集相关磁盘快照，报告实际释放空间、未处理项，以及清理内容能否恢复。
