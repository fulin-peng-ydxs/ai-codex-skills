# 磁盘使用分析报告固定模板

## 完整模板

````document-template
# 磁盘使用分析报告

## 1. 概览与证据范围

- 范围、时点与资源压力：{{@目标卷与扫描路径、采集起止/时区、统计入口及单位、卷容量/已用/可用/使用率；排除范围、权限和测量口径差异说明限制}}
- 当前结论与分类摘要：{{@证据支持的主要判断、分类统计和置信限制}}

## 2. 高占用与处理明细

- 排名与选择依据：{{@各资源维度排名及明细选择；无对象写条目情况及原因}}

### 对象：{{@目录或文件名称}} <!-- repeat -->

- 路径与大小：{{@已核实的完整路径、所属卷、采样时点、大小及单位、采集入口；注明逻辑大小或实际占用等工具口径，未知不混用}}
- 内容类型与用途依据：{{@内容抽查、应用配置或清单等用途证据、所属应用和仍在使用情况；只凭目录名的判断标为推断}}
- 占用关系与聚合口径：{{@与父子目录/其他候选的包含和重叠关系、实际涉及的挂载/链接/共享占用及去重方式；不能可靠拆分的部分说明限制}}
- 清理候选与预计空间：{{@具体候选子集、所属卷、预计可释放量的计算依据及不确定部分；不将目录总大小直接当作释放量，已纳入其他候选的空间不重复累计}}
- 风险、备份与确认条件：{{@依赖和数据损失风险、可恢复方式/备份状态及执行前需确认的精确范围；未知保留缺口}}
- 建议操作与复核方法：{{@建议的应用入口或精确动作、前后在同一卷/范围与单位下的复测方式及成功判据；获准执行后才写实际释放量，说明并发写入和测量差异等影响}}

## 3. 后续安排与盲区

- 处理顺序与依赖：{{@优先级引用明细；预计空间不重复累计，未执行不能写已释放；诊断建议不授予实际操作权限}}
- 测量盲区与后续：{{@权限、指标、瞬时性或范围缺口及影响和补测入口}}
````

## 填写与内容验收

默认保留前10个高占用项，有依据的清理候选即使不在排名内也补入同一明细；候选不凑数。
