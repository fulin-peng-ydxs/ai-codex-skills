# 技能边界验证案例

## 用途与执行

仅在创建、维护或复查本技能时使用，不是股票研究的数据来源或运行时审批清单。规则权威来源仍是[方法](methodology.md)、[数据契约](data-contract.md)和[维护契约](tracking.md)；本文件保留可重复的边界输入及预期行为，不维护另一份算法。

以下均为合成夹具，不对应真实证券。除明确缺失、未核验、过期或冲突项外，题设指定资料视为已按契约核验；该约定仅用于隔离规则验证，真实分析必须逐项取证。金额均为同一模拟单位。原始实际数据之外的研究情景须有题设提供的依据，不能借测试惯例放宽真实任务门槛。

执行时把“输入与请求”交给未看到预期结果的独立执行者，并提供当前技能及运行资源；执行者不要读取本文件的预期列。记录实际答复后逐项比对，不能只检查关键词。数值用独立算术抽核，缺数案例同时检查是否偷渡到摘要、总分、估值、价格动作或状态文件。规则修改后重跑受影响案例及共用缺数场景；出现新问题先修正规则，再复测。

## 评分边界

| ID | 输入与请求 | 预期行为 |
| --- | --- | --- |
| G01 | 五年治理资料完整，无重大或一般缺陷，人员披露交接充分；求评分15 | 唯一2分 |
| G02 | 治理资料完整，无重大警示，有一般缺陷正在整改，人员稳定；求评分15 | 唯一1分，不能命中2分 |
| G03 | 治理资料完整，五年内有重大警示且之后已整改；求评分15 | 唯一0分，说明整改现状，不抹去历史 |
| G04 | 没有已知重大警示，但一年监管资料未取得；求评分15 | 未评分，不把缺资料判成1分或无风险 |
| G05 | 无重大或一般缺陷，但有证据证明人员交接披露不足；求评分15 | 唯一1分，区分已证实不足和未取得材料 |
| F01 | 十年股权稀释性融资清单完整且为空；期间有正常纯债务；求评分13 | 唯一2分；纯债务留在财务安全分析 |
| F02 | 所有股权稀释性融资均到期达标，无违规且无实质每股损害，证据完整；求评分13 | 唯一2分 |
| F03 | 一笔股权融资仍在原定兑现期，当前进度、用途、无每股实质损害已核实；未来收益尚未到期；求评分13 | 唯一1分；未到期未来收益不是应披露实际值缺失 |
| F04 | 一笔股权融资已到原定兑现期，回报低于承诺，但无违规且已核实无实质每股损害；求评分13 | 唯一1分，无规则空档 |
| F05 | 股权融资到期未达标，并已证实实质每股损害；求评分13 | 唯一0分 |
| F06 | 股权融资项目承诺已达标，但仍有已证实融资所致实质每股损害；求评分13 | 唯一0分，达标不能覆盖损害 |
| F07 | 一笔已兑现达标无损害，一笔仍在原计划期且无已知不利，全部当前应有证据完整；求评分13 | 唯一1分，按最差已核实项目 |
| F08 | 一笔已证实违规，另一笔到期项目实际回报未取得；求评分13 | 整项未评分、汇总受阻；违规事实可单列，不以0分掩盖缺数 |
| F09 | 股权融资到期，实际回报已取得，但没有可核验承诺目标或每股影响依据；求评分13 | 未评分，不默认正常或中档 |

## ROIC 与价值起点

| ID | 输入与请求 | 预期行为 |
| --- | --- | --- |
| R01 | 报表利润总额15、费用化融资利息0、其中非经营现金收益5；证据证明各项统一20%税率且无特殊税差；期初期末权益加债务均150、对应非经营净资产均50；求ROIC | 经营EBIT10、NOPAT8、平均经营资本100、ROIC8%，不算12% |
| R02 | 利润总额15、费用化利息2、非经营净收益5；合并所得税3、非经营净税费1、已实现利息税盾0.4；平均经营资本100；均有附注证据；求ROIC | 经营EBIT12、经营税2.4、NOPAT9.6、ROIC9.6% |
| R03 | 利润总额8、利息0、非经营净损失为−2；同税率20%已证实；平均经营资本100；求ROIC | 加回非经营损失后经营EBIT10，ROIC8%，不能把亏损再次扣除 |
| R04 | 已知有非经营收益，但金额和对应税项尚未取得，其余ROIC输入齐全；求ROIC | 不给ROIC数值或回报判断，不假设调整为零 |
| R05 | 经营利润、资本都已核验，但仅有合并有效税率，没有经营税或税率简化条件证据；求ROIC | 阻断NOPAT及ROIC，不直接套合并税率 |
| R06 | ROIC调整完整，期初期末经营投入资本均0；求ROIC | 数学不适用，不输出无穷或0% |
| E01 | 公允价值专项；已选直接归母普通股利润×PE，三情景利润8/10/12、对应倍数10/12/14、稀释股本10，所有口径及参数依据齐全；另知净债务30；求价值区间 | 股权价值80/120/168，每股8/12/16.8；不再扣30，EV桥接不适用 |
| E02 | 公允价值专项；FCFF模型各输入齐全并已算得企业价值80/100/120；不在EV内的非经营资产10、债务30、少数股东5、其他非普通股索取权0均核验，普通股10；求三情景股价 | 股权55/75/95，每股5.5/7.5/9.5，完整桥接不重复加现金 |
| E03 | 与E02相同，但少数股东金额未知；求价值区间 | 股权和每股区间受阻；可展示独立已算EV，不默认少数股东为0 |
| E04 | 与E01相同，但乐观情景的倍数依据未取得；求三情景区间 | 乐观情景及整体区间受阻，不用两档拼完整区间；其余独立算值仅作局部结果 |

## 依赖与专项范围

| ID | 输入与请求 | 预期行为 |
| --- | --- | --- |
| D01 | 完整研究中独立DCF的全部输入、三情景、价值桥接和股本齐全，其参数未引用同业或历史倍数；历史PE仅119个月；其他核心均齐 | 可输出DCF局部计算；十年分位、评分12和所有聚合分受阻，完整报告及完整基线不可成立 |
| D02 | 所选倍数模型的倍数依据为十年历史PE，但序列只有119个月；求公允价值 | V受阻，不得事后改称历史数据无关 |
| D03 | 所选倍数模型依据至少两家同业，只有一家取得数据；求公允价值 | 同业比较及消费其参数的V受阻，不临时改模型逃避 |
| D04 | 独立DCF不引用历史PE，历史PE缺一个月；DCF的WACC输入也未取得；求公允价值 | DCF仍受阻，不能以历史不相关为由忽略WACC缺失 |
| D05 | 完整研究M0—M6和15项均齐，但V的折现率缺失；未请求三档价或仓位 | V是完整研究核心，报告部分完成；不能标V未请求，也不能建立完整基线；A/P可标未请求 |
| Q01 | 仅问过去12个月股息率：窗口内全部已实施同股本每股分红1元、当前价20元，日期与调整均核验；现金流表未取得 | 股息率5%，该专项完成；不要求现金流或跨期增长抽核，不升级完整结论 |
| Q02 | 与Q01相同，但当前价格未取得；只问股息率 | 股息率受阻，不用旧价、估计价或行业均值 |
| Q03 | V已完整，用户要求三档观察价，但M3偿债核验和安全边际依据未取得 | A受阻，不能把V区间当三档价或行动条件 |
| Q04 | A已完整，用户要求仓位，但现有组合和风险预算未给 | P受阻，不默认三等份或通用比例 |
| Q05 | 任一应有评分输入是unverified、stale或conflict，另外14项可评分；要求当前总分 | 该项及所有聚合分受阻；不得以已取得、旧分或平均分替代 |

## 跟踪与输出契约

| ID | 输入与请求 | 预期行为 |
| --- | --- | --- |
| T01 | 已有1.0完整基线，要求按当前方法跟踪，不提供重算资料 | 保留历史基线，标需重建；不直接继承旧分或拼出当前总分 |
| T02 | 档案已需重建，当前有效基线为空；本次只补齐一个缺口且新增一份可核验公告，用户要求维护 | 保存新证据和缺口状态，但仍需重建，不恢复可用或部分待核验，不输出维持判断 |
| T03 | 1.1有效基线，最新现金流未取到，机构预测共同样本只有2家，其余核验齐全 | 对应现金流、预测与依赖判断受阻，档案部分待核验；历史单项仅在独立窗口未变且已核实可复用时保留，不能沿用当前总分 |
| O01 | 主体与一般工商企业适用性已经核验；请求完整研究，仅另提供Q01的分红与价格合成资料，其余必需输入都缺失 | 按full模板试填部分报告；仅股息率等真正独立结果可生成，V/评分/综合受阻，不把未请求A/P混同V，未建立完整基线 |
| O02 | 请求跟踪并维护T02中的档案 | 按update或blocked的适用分支及state模板试填；指针为空、历史报告失效标识、缺口和下次触发一致，不假装创建自动化 |

O01/O02 的试填文件只放独立临时目录；对所用模板执行共用检查器，再检查语义。格式反例至少覆盖缺章、错序、缺字段、非法新增、空值和占位残留；不另造模板检查器，不将格式PASS当行为PASS。实际联网取数、历史覆盖、授权接口和并发持久化未实测时单列未验证，不用合成夹具声称通过。
