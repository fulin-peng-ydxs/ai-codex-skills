# 技能边界验证案例

## 用途与执行

仅在创建、维护或复查本技能时使用，不是股票研究的数据来源或运行时审批清单。规则权威来源仍是[方法](methodology.md)、[数据契约](data-contract.md)和[维护契约](tracking.md)；本文件保留可重复的边界输入及预期行为，不维护另一份算法。

以下均为合成夹具，不对应真实证券。除明确缺失、未核验、过期或冲突项外，题设指定资料视为已按契约核验；该约定仅用于隔离规则验证，真实分析必须逐项取证。金额均为同一模拟单位。原始实际数据之外的研究情景须有题设提供的依据，不能借测试惯例放宽真实任务门槛。

执行时把“输入与请求”交给未看到预期结果的独立执行者，并提供当前技能及运行资源；执行者不要读取本文件的预期列。记录实际答复后逐项比对，不能只检查关键词。数值用独立算术抽核，缺数案例同时检查是否偷渡到摘要、总分、估值、价格动作或状态文件。规则修改后重跑受影响案例及共用缺数场景；出现新问题先修正规则，再复测。
