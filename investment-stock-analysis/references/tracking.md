# 研究维护与保存

模式选择以[主入口模式表](../SKILL.md#输入与前置条件)为准；原始记录与计算门槛见[数据契约](data-contract.md)。本文件只规定当前成果如何读取、更新和发布。

## 文件分工与唯一记录

保存位置优先用用户指定目录及现有公司目录；专用仓库用 `<交易所>-<代码>/`，其他投资项目默认 `agent-works/stock-research/<交易所>-<代码>/`，无项目用 `~/investment-research/<交易所>-<代码>/`。以主体/市场/代码关联，简称变化不另建重复公司档案，不把技能仓库当研究项目。

| 固定产物 | 唯一职责 | 维护方式 |
| --- | --- | --- |
| `report.md` | 面向读者的分析、评分、估值/计划、风险/证伪/催化剂、缺口摘要和下次检查条件 | 对应位置就地更新；保留未变且仍有效的正文，不追加逐轮全文或备份 |
| `evidence/research.json` | 一套可追溯的计划、来源、输入、计算、分析依赖、缺口及实际核验记录 | 按[记录结构](data-contract.md#研究记录的保存结构)合并维护，本次只更新变化项；报告表格从这些记录形成，不另维护相同语义的索引、数据表或核验报告 |
| `state.md` | 发布元数据与报告/研究记录的校验值，供并发和中断识别 | 自动发布时同步更新；不重复保存判断、评分、风险、缺口或完整研究资格 |
| `evidence/`内原始资料 | 分析实际使用的财报、公告、行情与必要原文提取 | 按文档身份保存，未变文件复用；历史财报是跨期输入，不是旧报告备份 |

不要求额外 `source-index.md`、`verification.md`、分散的data/calculations/dependencies/gaps/score等JSON或运行回执。必要的来源、公式、评分依据、缺口和核验结果均放进research记录；报告保留读者判断所需的主要来源链接和计算。已有特殊附件确有独立用途时可以保留，不为凑齐目录创建文件。仓库入口仅在公司或路径变化时维护链接。

## 三种模式的读写范围

| 模式 | 读取与核验 | 保存与时效 |
| --- | --- | --- |
| 完整研究 | 完整契约全部核心；未变、未重述且仍适用的历史证据可复用 | 按full模板创建或更新report及本轮研究记录，发布state；资料未齐仍保存部分报告，不伪称完整 |
| 跟踪更新 | 当前报告与其证据、新一期/事件材料，以及受影响分析和上下游。定期跟踪覆盖下表类别；明确单事件只核实相关类别，其余记录复用依据和原时点 | 更新原报告对应位置及记录，最后发布state。既有部分报告可更新独立事实；不得把未知旧值当作不变，也不因此升级整体判断 |
| 专项分析 | 仅请求项目及真实依赖 | 默认不写文件。要求保存且已有完整结构报告时融入对应章节、同步消费方及摘要；无完整结构报告时用scoped模板保存report。未复核部分保留原时点，不借局部保存推进整份报告的全面核验时点或完整标签 |

仅保存/迁移读取指定成果和实际依赖，保持原截止、数值和验证状态，修复引用后保存，不补写新研究。旧目录有分散JSON或业务state时按实际用途读取；只有用户要求整理迁移时才合并并清理被替代文件，不能因技能更新自动改写既有档案。沿用旧格式也只更新受影响资料，不额外创建新旧两套同义记录。

## 跟踪的覆盖与比较

| 类别 | 应核验的新事实或复用依据 |
| --- | --- |
| 财报与经营 | 新三表、附注、更正、分部/KPI，以及单季同比环比所需基期；无新季报明确说明，不制造季度数字 |
| 价格与资本结构 | 所用最近收盘、停复牌、分红除权、股本、融资、回购、债务；除权/增发重算相关每股值和触发条件 |
| 预测与估值 | 共同机构样本、有效期、年度滚动、分歧，以及消费它们的倍数/V模型；不临时改样本或路线规避缺数 |
| 驱动与行业 | 业务驱动的实际最新发布、历史位置、市场边界及政策，失败查询不能当持平 |
| 风险与治理 | 覆盖期间公告、审计、监管、诉讼、担保、关联/控制权/人员；保留风险发生及整改的实际时点 |
| 假设与计划 | 原逻辑、证伪、6—12月催化及三档A/P的估值/损失/触发/比例依据；需要个性化时另核用户约束 |

先读取本轮要比较的旧值、日期、方法及来源，再更新文件；不为比较另存报告副本。只要旧新对应事实可比且已核实，即可陈述该项变化；没有整体完整依据时不输出总体维持/上调/下调评级或行动。旧资料无法读取时只保留独立新事实和缺口，不虚构变化，不自动启动完整重做。

对话围绕新事实、驱动、评分/估值、计划、结论说明增量；有新季报才展示有据季度指标，详细程度以理解变化为准，不强制五段文件、固定季度空表或篇幅比例。持久化始终更新report原位置。

## 建立与恢复基线

“完整基线”只是本轮开始时的报告已通过[完整判据](data-contract.md#模块依赖和阻断传播)，可支持总体判断比较；不需要独立历史文件或专门状态机。完整研究资格以报告和analyses实际门槛为准，state不再登记另一份资格。

主体、方法、模型或业务范围发生重大不可比变化时，在报告标需重建，停止受影响旧结论；重建按授权完整重做，仍覆盖同一报告。补缺重算全部真实消费方，只有全部核心通过才恢复完整。错误规则不能记成缺数，未执行核验不能记成未披露。

`T-`逻辑、`R-`风险、`C-`催化和`G-`缺口沿用稳定ID；长原因和证据分别存于研究记录，报告展示必要结论与摘要，已解决条目保留当前处置及事实时点。用户停止维护时在报告注明，自动化状态只有真实工具结果才可改变；不把保存档案当作已建立监控。

## 历史回看与时间边界

历史截止是时间条件，不减少对应模式的分析范围。仅使用该时点已公开证据，不把今天修订值当成当时已知。默认对话交付，明确要求独立保存时用指定位置或 `history/<截止日期>/report.md`及其记录；同一历史成果就地更新，不覆盖当前报告/state。

当前发布截止不得倒退；较旧任务后完成时不应用、不自动另存过时备份，也不改截止绕过。同一截止有正式更正可直接修订，重核全部受影响消费方。必要的历史财报原件可以保留；生成报告默认只维护最新一份，Git提交/推送需另有授权。

## 一致性与发布

state的“研究截止”与报告同名字段一致，表示当前版本使用资料的截止上界，不等于所有分析均已复核至该日。局部更新须在报告研究范围注明本次覆盖、原全面核验时点及未变项复用范围，并在plan/analyses保留各项实际核验时点；只有全套必需项目重新核验或确认有效复用后，才可推进全面核验声明或保持相应完整标签。

先检查当前state记录的报告/研究记录哈希；不符、文件缺失或中断时，先核验实际内容，不能仅凭state或文件修改时间假设已发布。采用旧格式时仅核验其实际记录的项目，不猜补时点或哈希。

新建或已合并档案使用以下两项核心文件和本文件state模板。旧格式局部更新沿用其现有文件映射及state结构，核对并更新实际受影响的校验条目，模板只检查受影响部分；不为满足新结构新增一套research或强制迁移。

在任务临时目录准备变化文件及候选state，完成事实、依赖、计算、引用和适用模板检查。复用[发布工具](../scripts/publish_state.py)：

1. 记录原state字节SHA-256，不存在为 `absent`。候选state填写带时区的研究截止；新结构填写两项核心哈希，旧格式填写本次实际更新的既有文件校验值。
2. 临时JSON映射以 `report.md`、`evidence/research.json`及本次新增/变化的原始附件固定相对路径为键，候选文件路径为值。旧格式可映射其既有evidence文件；未变文件不复制，state及锁不放进映射。
3. 执行 `python3 <技能目录>/scripts/publish_state.py --directory <公司目录> --candidate <候选state> --artifacts <映射JSON> --expected <原SHA或absent>`。同一 `.state.lock` 内核对哈希和截止，替换变化文件，最后发布state并回读，不生成备份。
4. 冲突退出3则重读并重新核验，不能只换expected；锁超时4不删锁抢占；时点/时区错误5不覆盖。旧state时区只在原证据能确认等价时刻时用 `--normalize-time`归一化字段。成功后按本次实际发布文件回读哈希、截止和引用，再清理本轮临时文件。

工具只验证写入边界，不核验投资语义。多文件替换不是事务，中断可能部分成功；按实际内容完成同批发布或重建一致记录，不假设全回滚、不用旧state声称维护成功。发布失败不阻止已通过门槛的独立分析交付，但须说明保存未完成。

## 发布状态模板

state仅保留发布信息。报告状态、缺口、下次检查及自动化结果在report/research各自位置维护，不再复制进state。

````document-template state
# {{@公司与代码}}研究发布状态

- 证券主体：{{@法人主体、交易所和代码}}
- 研究截止：{{@带时区ISO 8601；与报告研究截止一致，全面核验范围在报告说明}}
- 方法版本：{{@计算与评分版本}}
- 当前报告：{{@唯一report.md链接}}

## 当前产物

| 产物 | 固定路径 | SHA-256 |
| --- | --- | --- |
| 报告 | {{@report.md链接}} | {{@报告真实哈希}} |
| 研究记录 | {{@evidence/research.json链接}} | {{@记录真实哈希}} |
````
