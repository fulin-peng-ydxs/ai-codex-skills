# 数据契约

## 来源与访问

先发现本次可调用工具和权限，不写死 iFinD 路径、函数签名或套餐。用户指定的可靠来源优先；已授权商业服务可用于提取，但仍保留原始披露依据。无插件时直接查公开资料，不推断已取得商业服务权限。

| 数据类别 | 优先依据与候选入口 | 运行要求 |
| --- | --- | --- |
| 财报、分部、分红、融资和公告 | [巨潮](https://www.cninfo.com.cn/)、[上交所](https://www.sse.com.cn/)、[深交所](https://www.szse.cn/)、[北交所](https://www.bse.cn/)、公司 IR；结构化候选 [Tushare 财报](https://tushare.pro/document/2?doc_id=33) | 查合并报表、附注及更正公告，关键字段与原始披露核验 |
| 行情与历史估值 | 授权服务；[Tushare 每日指标](https://tushare.pro/document/2?doc_id=32) | 核实交易日、停牌、股本、PE 类型、PB 定义及覆盖期；价格序列不等于估值序列 |
| 券商预测 | 原始研报或可核验服务；[Tushare report_rc](https://tushare.pro/document/2?doc_id=292) | 逐机构、报告日、预测年度取数，不把业绩预告或单份研报称一致预期 |
| 行业驱动 | [国家统计局](https://www.stats.gov.cn/sj/)、行业官方发布；能源可用 [EIA](https://www.eia.gov/opendata/) | 明确品种、地区、单位、频率及发布日期；期现货、出厂价与零售价不可混替 |
| 备用提取 | [AKShare](https://github.com/akfamily/akshare) | 记录实际上游；处理接口变更和限流，不承诺长期可用 |

公开可读不等于免费 API 或无限访问。接入时读当前文档核实权限、分页、频率及使用条件，不固化积分或价格。失败先区分鉴权、限流、网络、参数和字段缺失；按提供方间隔重试，无指引时同请求最多再试一次，随后换独立来源或阻断。替代源须满足同一契约；同上游镜像不算独立核验。

## 可追溯记录

每个使用数据项记录：稳定数据 ID、主体、指标/原字段、值、单位、币种、合并/母公司范围、报告期/交易日、公告或生效日期、获取时间、原始 URL 或数据集与查询参数、页码/表名/字段、版本/重述情况、状态。计算值另记公式和输入 ID；预测记机构及目标年度；情景假设记依据 ID、取值理由、区间及敏感性。

状态为 `verified`（核验可用）、`unverified`（已取得但来源、时点或口径尚未核验）、`missing`（未取得）、`not_disclosed`（材料证实未披露）、`stale`（不符合时点）、`conflict`（冲突未解）、`inapplicable`（数学或业务不适用）。只有 verified 可进入适用分析。关键口径或发布日期无法确认，不能标为 verified。保存许可允许的原始快照，不保存凭据。

冲突先统一单位、范围、期间和版本，再查原始披露及修订。当前研究可采用最新重述并保留前版；历史回看使用当时版本。仍无法解释则阻断，不平均冲突值或任选较有利数据。

## 模块依赖和阻断传播

下表为主框架完整研究的最低要求；取数前确定具体指标与依赖 ID。复合模块可按明确子项独立出结果，但任一必需子项未完成，该模块与完整报告均不完整。不得临时把缺失项降为可选。

| 模块 | 必需输入与期间 | 缺失时禁止生成 |
| --- | --- | --- |
| M0 主体与适用性 | 官方主体、代码/交易所、行业、上市日、重组和业务连续性、截止时点 | 主体不明停止全部分析；行业不明停止适用性判断 |
| M1 盈利 | 5 个完整年度可比 ROE、收入/成本、归母净利、ROIC 所需字段；最新季度及比较期 | 缺字段所依赖的指标和评价；M1 总结 |
| M2a 历史成长 | 相隔 5 年的 6 个年度值；最近 3 个单季与同比、环比所需期间 | 相应 CAGR、季度增长与趋势；独立齐全指标可输出 |
| M2b 未来成长 | FY1—FY3 机构预测、样本机构、日期、具体年度及实际利润基准 | 三年预测增长、预测方向与评分 14；不能以自建情景替代 |
| M3 财务安全 | 5 年 OCF、合并净利、资本开支；最新资产负债表、TTM 利息/EBITDA、债务及期限、受限资金和担保附注 | 相应现金流/偿债分析；综合财务安全结论 |
| M4a 业务与护城河 | 最新分部收入、成本/毛利与合并勾稽；近 5 年业务证据、市场边界、份额和竞争证据 | 相应利润归因、护城河或排名判断；毛利不能冒充净利润贡献 |
| M4b 驱动与周期 | 1—2 个业务证据支持的驱动；各自当前值及完整周期可比序列，通常 5—10 年 | 当前方向、历史位置及敏感性结论；未覆盖完整周期不称周期已校准 |
| M5a 回报 | 5 年按利润所属年度归集的已实施现金分红、归母净利，回购注销/激励交付及股本变动；最新价格 | 相应分红持续性、支付率、股息率与每股回报结论 |
| M5b 估值与同业 | 当前价格/股本、适用盈利/净资产、10 年同口径估值序列；至少 2 家业务可比同业的所用指标；模型全部输入 | 相应分位、同业估值、价值区间；进一步阻断价格档位及行动 |
| M6 风险与治理 | 最新审计意见，5 年治理及监管/重大诉讼，10 年融资与稀释，截止时点公告检索；各适用风险证据 | 未核验类别评价及总体无重大风险表述；已证实风险仍可披露 |
| S 评分 | 方法表各项完整输入与适用性 | 相应单项分数；任一受阻则总分、评级、汇总分停止 |
| V 情景与价格观察 | M5b、驱动模型、资本结构、三情景输入和证伪信号可用，M6 无待核验重大警示 | 缺输入的情景估值、三档观察价及触发结论 |
| P 仓位（按请求） | V 可用，用户期限、组合/持仓、单股上限、风险预算及交易约束 | 买入/加仓/退出比例，不以通用比例代填 |

M0—M6 各适用子项和 S 是主框架核心。V 在要求价格区间或交易条件时必需，P 仅在请求仓位时启用。综合研究判断依赖全部核心；局部缺数时只生成无依赖局部结果，不给整体仍优质等结论。每个阻断写明缺项和影响，不只留空或写 N/A。

## 时点与窗口

- 年度质量用最近 5 个已披露完整年度；5 年 CAGR 两端相隔 5 年，需 6 个年度值。资产负债用最新已披露季末，期间收益/利息用可比 TTM，不以旧年末替代。
- 先核实累计或单季。累计表单季 Q2=H1−Q1，Q3=9M−H1，Q4=FY−9M；同比、环比补齐所需单季。资产负债表不差分。TTM=上年全年+本年累计−上年同期累计，均需同口径。
- 当前价为截止时点最近已完成交易日收盘价，记录停牌/非交易日。FY1—FY3 写具体公历年，以最新已披露完整实际年度后连续三年为定义；已结束但尚无正式年报的年度仍标预测，不能冒充实际。
- 预测纳入截止前 180 天内且未被重大事件明确推翻的材料；同机构同年度留最近一份；至少 3 家机构对三个年度均有可比预测，用共同机构样本的逐年中位数并列数量和范围。不足则 M2b 阻断。此为本框架门槛，不宣称行业统一标准。
- 十年分位默认截止时点前最近 120 个完整自然月各月末最后交易日的同口径 PE-TTM 或 PB；当前未结束月份不进入历史样本。须覆盖十年窗口且样本全齐。丢月、上市不足或部分期间比率不适用，阻断该十年分位。可报告实际覆盖期事实，不冒充十年或用于该项评分。
- 历史估值使用各历史时点已可获得的财报与股本；自行重建按披露日生效，不能用今天盈利/股本回填。复权价用于收益率，不直接除未经同口径调整的 EPS。
- 行业指标按实际发布日期和正常频率核验最新一期，不能统一用近 30 天代替。同业记录业务、地区、会计、杠杆与阶段差异；不足两家合理可比公司则比较受阻，不凑数。
