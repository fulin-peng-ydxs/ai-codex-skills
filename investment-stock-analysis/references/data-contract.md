# 数据契约

## 来源与访问

先发现本次可调用工具和权限，不写死 iFinD 路径、函数签名或套餐。用户指定的可靠来源优先；实际可用且已授权的 iFinD 优先用于提取公开数据，再用原始披露核验。不可用则转官方公开资料或其他可追溯服务，在摘要注明来源变化和原因，不推断已取得商业服务权限。三大报表分别核验返回范围，不能把接口部分返回当完整取数。

| 数据类别 | 优先依据与候选入口 | 运行要求 |
| --- | --- | --- |
| 财报、分部、分红、融资和公告 | [巨潮](https://www.cninfo.com.cn/)、[上交所](https://www.sse.com.cn/)、[深交所](https://www.szse.cn/)、[北交所](https://www.bse.cn/)、公司 IR；结构化候选 [Tushare 财报](https://tushare.pro/document/2?doc_id=33) | 查合并报表、附注及更正公告，关键字段与原始披露核验 |
| 行情与历史估值 | 授权服务；[Tushare 每日指标](https://tushare.pro/document/2?doc_id=32) | 核实交易日、停牌、股本、PE 类型、PB 定义及覆盖期；价格序列不等于估值序列 |
| 券商预测 | 原始研报或可核验服务；[Tushare report_rc](https://tushare.pro/document/2?doc_id=292) | 逐机构、报告日、预测年度取数，不把业绩预告或单份研报称一致预期 |
| 行业驱动 | [国家统计局](https://www.stats.gov.cn/sj/)、行业官方发布；能源可用 [EIA](https://www.eia.gov/opendata/) | 明确品种、地区、单位、频率及发布日期；期现货、出厂价与零售价不可混替 |
| 备用提取 | [AKShare](https://github.com/akfamily/akshare) | 记录实际上游；处理接口变更和限流，不承诺长期可用 |

公开可读不等于免费 API 或无限访问。接入时读当前文档核实权限、分页、频率及使用条件，不固化积分或价格。失败先区分鉴权、限流、网络、参数和字段缺失；按提供方间隔重试，无指引时同请求最多再试一次，随后换独立来源或阻断。替代源须满足同一契约；同上游镜像不算独立核验。

阻断的是依赖该输入的计算，不是后续取证。形成最终报告前，先完成能取得资料的检索与核验：结构化接口缺项时查原始财报和附注；口径冲突时查比较列、更正及原表；分页目录核对去重数量与总数；单一源失败时查适用替代来源。已有可靠且未失效的资料可以复用，不重复下载已核内容。未检索、下载后未核、公式未执行等属于工作未完成，应继续处理，不能标成公开数据不可得。完成这些动作后仍受阻，才记录具体字段、所需期间、已查来源及结果、失败类型、影响和恢复条件；用户要求停止或客观访问限制阻止继续时如实说明实际未完成项，不把它们改写为“未披露”。

缺口原因须区分：业务或数学上不存在；所查原文没有披露所需细分；已查来源未收录合格样本；授权/访问失败；冲突或覆盖不足。负面检索结论只覆盖实际检索范围，不要求无限搜索，也不因单次空响应声称全市场无数据。

## 可追溯记录

每个使用数据项记录：稳定数据 ID、主体、指标/原字段、值、单位、币种、合并/母公司范围、报告期/交易日、公告或生效日期、获取时间、原始 URL 或数据集与查询参数、页码/表名/字段、版本/重述情况、状态。正文数据和判断就近标来源 ID 与日期，不只在文末堆链接；iFinD 提取值标注数据集及 as of 时点，网络资料链接原文或用可回溯脚注。计算值另记公式和输入 ID；预测记机构及目标年度；情景假设记依据 ID、取值理由、区间及敏感性。

状态为 `verified`（核验可用）、`unverified`（已取得但来源、时点或口径尚未核验）、`missing`（未取得）、`not_disclosed`（材料证实未披露）、`stale`（不符合时点）、`conflict`（冲突未解）、`inapplicable`（数学或业务不适用）。只有 verified 可进入适用分析。关键口径或发布日期无法确认，不能标为 verified。保存许可允许的原始快照，不保存凭据。

冲突先统一单位、范围、期间和版本，再查原始披露及修订。当前研究可采用最新重述并保留前版；历史回看使用当时版本。仍无法解释则阻断，不平均冲突值或任选较有利数据。

## 模块依赖和阻断传播

下表为主框架完整研究的最低要求；取数前按所选模式、方法和实际公式锁定具体指标与依赖 ID。专项仅启用请求的分析项及其真实依赖；完整研究必须覆盖所有核心，不能因取数失败删掉一项。复合模块按明确子项独立判定，但任一必需子项未完成，该模块及完整报告均不完整。

依赖记录必须落到可执行的分析项，例如 M1-ROIC、M5a-股息率、M5b-history、V-悲观情景，并区分原始输入、计算输入和必需上游结论；父模块只汇总状态，不把同级项目自动互设为依赖。所有原始必需输入均为 verified 且必需上游通过，才允许生成该项。缺项在所有真实消费方传播，不能仅标记原数据表，也不能以拆项之名绕开原先选定的输入。

| 模块 | 必需输入与期间 | 缺失时禁止生成 |
| --- | --- | --- |
| M0 主体与适用性 | 官方主体、代码/交易所、行业、上市日、重组和业务连续性、截止时点 | 主体不明停止全部分析；行业不明停止适用性判断 |
| M0-history 十年财报覆盖 | 最近 10 个已披露完整年度的合并利润表、现金流量表、资产负债表及实际分析所需附注；覆盖年度和缺项逐年记录 | 十年历史全景、周期校准及完整报告；不连带阻断已有完整独立输入的五年评分或专项 |
| M1 盈利 | 5 个完整年度可比 ROE、收入/成本、归母净利；最近完整年度 ROIC 的经营损益、税项桥接及期初期末资本归属；明确要求长期 ROIC 时另锁相应历史窗口；最新季度及比较期 | 缺字段所依赖的指标和评价；M1 总结；仅 ROIC 调整缺失不自动阻断有完整独立输入的报表口径 EBITDA |
| M2a 历史成长 | 相隔 5 年的 6 个年度值；事前确定最近 2—3 个单季及同比、环比所需期间；十年周期校准依赖 M0-history 与 M4b | 相应 CAGR、季度增长与趋势；周期校准另判定，不以缺数为由把已选 3 季改 2 季 |
| M2b 未来成长 | FY1—FY3 机构预测、共同样本机构、日期、具体年度及实际利润基准；利润、收入、净资产预测分别用于前瞻 PE/PS/PB | 对应预测增长、预测倍数、方向与评分 14；各指标按真实输入阻断，不能以自建情景替代机构预测 |
| M3 财务安全 | 5 年 OCF、合并净利、资本开支；最近年报有息债务/全年 EBITDA、5 年年报资产负债率；最新资产负债表、TTM 利息/EBITDA、债务及期限、受限资金和担保附注 | 相应现金流/偿债分析；综合财务安全结论 |
| M4a 业务与护城河 | 最新分部收入、成本/毛利与合并勾稽；近 5 年业务证据、市场边界、份额和竞争证据 | 相应利润归因、护城河或排名判断；毛利不能冒充净利润贡献 |
| M4b 驱动与周期 | 1—2 个业务证据支持的驱动、当前值及事前确定的历史区间；公司十年周期校准以十年财报及实际用于该判断的十年驱动序列为依据，周期更长时补足完整周期 | 对应驱动方向、历史位置及敏感性；用于十年周期判断的必需序列缺失即阻断该判断，不退为五年；不把未用于十年判断的每个驱动一律加成十年必需 |
| M5a 回报 | 完整研究取 5 年已实施分红、归母净利、回购注销/激励交付、股本及价格；单问过去 12 月股息率仅需该窗口全部已实施每股现金分红、股本调整和当前价格 | 缺失输入所依赖的分红持续性、支付率、股息率或每股回报结论；专项股息率不要求无关现金流表 |
| M5b-current 当前与前瞻估值 | PE、PB、PS 各自的当前价/市值、股本及同口径盈利/净资产/收入、日期；FY1—FY3 倍数另需相应机构预测；成长型另核 PEG 输入 | 对应倍数或 PEG，不把一种倍数的缺项传播给无依赖的另一种，也不能省略缺项装作估值已完整 |
| M5b-history 历史位置 | PE、PB、PS 的适用当前值及十年同口径估值序列；评分 12 事前选定 PE-TTM 或 PB；频率及样本按下文锁定 | 对应十年分位和消费它的评分/估值；不能用股价序列替代估值或事后降采样掩盖缺点 |
| M5b-peers 同业参照 | 事前选定 1—2 家合理可比公司与目标公司的 ROE、ROIC、毛利率、净利率、PE、PB、PS、分红率及日期，前瞻指标同口径另列 | 对应指标比较；若 V 消费缺项则沿依赖阻断；不能把缺字段公司换成无可比依据的公司凑数 |
| M6 风险与治理 | 最新审计意见，5 年治理及监管/重大诉讼，10 年融资稀释清单、截止时点公告检索及适用风险证据；资本配置深入调查按方法中事前确定的实际论点与重大风险取依赖，不把每笔每股回报一律设为前置 | 未核验类别评价及总体无重大风险表述；已证实风险仍可披露 |
| S 评分 | 方法表各项完整输入与适用性 | 相应单项分数；任一受阻则总分、评级、汇总分停止 |
| V 估值推导 | 三档计划所用估值方法的全部原始输入、参数依据、适用价值桥接及股本；事前确定输出为点估值、区间或情景，记录实际消费的 M5b/M2b 子项 | 对应估值与依赖结论；不强制额外三情景模型，但已选的情景或区间边界缺项时不能改成单点绕过 |
| A 三档建仓价格与触发 | V 全部通过、当前价格/股本、价格安全边际依据、适用经营触发及证伪条件、M3 偿债与 M6 风险治理核验 | 三档价格区间、条件触发和行动判断；不能把有条件估值计算直接当买入依据 |
| P 三档计划比例 | A 可用；以本标的计划投入总资金为 100%的分母定义、分配方法及依据、各档风险/损失情景和触发顺序；个性化总资产比例或实际金额另需用户期限、组合/持仓、单股上限、风险预算、交易约束 | 对应分档比例；分配依据缺失不能默认三等份；私人组合缺失只阻断依赖该资料的个性化比例，不能伪称已有个人配置建议 |

完整研究必须包含 M0—M6（含十年三表及 M5b 各子项）、S、V、A 和 P；完整请求已经包含三档建仓计划，不需要另行请求价格或比例。任一必需部分受阻，不能生成完整综合判断或建立有效完整基线，不能改成未请求或默认值。P 的计划分配依据不可用即受阻；只有要求个性化配置时，用户资料才是其附加必需依赖。P 缺数不阻断输入独立齐全的 A、V 或其他结果。评分汇总单独依赖全部 15 项：任一项未评分则所有聚合分受阻；全部可评分但其他部分受阻时，仍须显示有据总分及框架评级并标明仅评分完成，不能借此宣称完整研究完成。

专项按明确限定的目标启用：仅问股息率不启用 V/A/P；只问公允价值启用 V；只问三档价格启用 V+A；问完整建仓计划或仓位启用 V+A+P。用户明确排除价格或仓位时遵守限定，交付范围限定的研究，不称本框架完整报告或建立完整基线；不能以用户未逐项点名推定其排除。以同业倍数估值，M5b-peers 是 V 必需；以历史分位选倍数，M5b-history 是 V 必需；独立 DCF 未使用它们时，其缺失不会阻断 DCF 计算，但仍阻断相应历史/同业分析、评分及完整报告。任何原始预测基础或所选折现率资料缺失，DCF 仍须停止，不得用自拟参数补洞。每个结果同时列出自身依赖是否齐全、整体是否仍有缺口，不以局部价格区间暗示整体研究完成或可采取行动。

## 时点与窗口

- 完整研究先取得近 10 个已披露完整年度三表；年度质量和评分仍取最近 5 年，5 年 CAGR 两端相隔 5 年，需 6 个年度值。评分 8、9 保留最近年报口径；当前偿债风险另核最新季末和可比 TTM，不用旧年报冒充当前，也不把新季度偷换进原年度评分。
- 先核实累计或单季。累计表单季 Q2=H1−Q1，Q3=9M−H1，Q4=FY−9M；同比、环比补齐所需单季。资产负债表不差分。TTM=上年全年+本年累计−上年同期累计，均需同口径。
- 当前价为截止时点最近已完成交易日收盘价，记录停牌/非交易日。FY1—FY3 写具体公历年，以最新已披露完整实际年度后连续三年为定义；已结束但尚无正式年报的年度仍标预测，不能冒充实际。
- 一致预期须有至少两家独立机构的可核验基础；同机构同年度取最新有效材料，核实其是否已被新财报、事件或新报告推翻，并记录公开日期与有效性依据，不能仅因存在旧数值就复用。三个年度使用可比共同样本；供应商汇总须披露可核验的样本与统计口径，自行汇总在取数前确定均值或中位数。没有真实多机构基础不称一致预期。若事前明确选择 3 家或 180 天窗口等更严格方法，其缺项仍必须阻断，不能事后缩样本或扩窗口。
- 十年分位默认最近 10 个完整年度的年末最后交易日同口径估值值（10 个年度样本），列明年频采样及粗粒度局限；如事前选定月频，则取最近 120 个完整月末样本。选定的十年窗口及各采样点必须全齐；年度样本不能冒称月频分位，月频缺点不能临时改年频规避。上市不足、丢点或适用比率为负时阻断对应十年分位。PE/PB/PS 各按适用口径核验，评分 12 只消费事前选定的 PE-TTM 或 PB。
- 历史估值使用各历史时点已可获得的财报与股本；自行重建按披露日生效，不能用今天盈利/股本回填。复权价用于收益率，不直接除未经同口径调整的 EPS。
- 行业指标按实际发布日期和正常频率核验最新一期，不能统一用近 30 天代替。同业事前选 1—2 家并说明业务、地区、会计、杠杆和阶段差异；仅 1 家时明确代表性局限。事前选了 2 家而其中一家必需数据缺失，仍阻断对应两家比较，不能事后删掉失败对象；确无合理同业则说明缺口，不凑数。
